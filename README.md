# Uber Eats Operational & Customer Intelligence System

## Project Overview
This project explores food-delivery operations and customer behavior using data analytics and machine learning.

## Objectives
- Generate and prepare synthetic operational data.
- Perform exploratory data analysis (EDA).
- Segment customers using clustering.
- Analyze customer reviews using NLP and sentiment analysis.
- Predict delivery times using regression.
- Explore hourly demand patterns and forecasting.
- Translate analytical findings into business recommendations.

## Tech Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- NLTK
- Statsmodels

## Project Structure
- `data/raw/` — raw input data
- `data/processed/` — cleaned data
- `notebooks/` — analysis notebooks
- `src/` — reusable Python scripts
- `reports/` — findings and business recommendations

## Workflow
The project will be developed incrementally, with changes tracked using Git and GitHub.
